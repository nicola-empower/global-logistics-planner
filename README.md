#  Global Logistics Planner

A custom-built, interactive dashboard for managing complex, multi-leg corporate travel and logistics. This single-page web application functions as a "single source of truth" for an entire project, tracking everything from itineraries and budgets to essential kit lists and office handoff procedures.

---

##  The Origin Story: From Personal Chaos to Professional Solution

This project began as a personal necessity. As a mum of three with a busy, and often chaotic, life, I found myself planning a complex international trip. Standard spreadsheets were too clunky, and note apps were far too fragmented. I needed a single, reliable source of truth for my itinerary, my budget, my packing list, and—most importantly—detailed handoff notes for my children's carers.

Seeing no tool that could truly cover all my bases, I built my own: the "My Wee Wander Planner".

This **Global Logistics Planner** is the professional evolution of that very concept. I applied the exact same logic—creating order from chaos, demanding a single source of truth, and ensuring meticulous handoff planning—to solve a complex **business** problem.

This demo (`index.html`) showcases how that same system is used to manage a high-stakes, multi-city "Tech Summit Roadshow" for a corporate client, proving the model's scalability and professional application.

##  Core Features

This dashboard transforms a chaotic list of logistics into a clean, interactive, and manageable plan:

* **Dynamic Itinerary:** Automatically sorts and displays a complex, multi-day itinerary, clearly separating travel legs, meetings, and ground transport.
* **Live Dashboard:** The main dashboard provides an at-a-glance view of the "Next Upcoming Event" and a list of "Action Items" (e.g., "Pack: Conference Presentation").
* **Interactive Kit List:** An interactive checklist for all essential tech, assets, and documents. Users can add new items and check them off as they're packed.
* **Project Budget Tracker:** A live budget tracker that separates "Fixed Project Costs" (like flights and venue hire) from "Variable Spending" (like per diems and client meals). New expenses can be added and categorized instantly.
* **Delegated Tasks & Office Handoff:** The "Kiddo Corner" concept, professionally reimagined. This module holds all critical office handoff details, emergency escalation contacts, secure login details, and delegated tasks.
* **Secure Document & Link Hub:** A central place to store all essential documents, passport/visa details, insurance policy numbers, and secure project links.

##  Tech Stack

* **Front-End:** HTML5, CSS3 (Modern, mobile-first design)
* **Core Logic:** Vanilla JavaScript (ES6+)
* **Data:** All data is handled by a local JavaScript object (`travelData`) in this self-contained demo version. The original "My Wee Wander Planner" proof-of-concept successfully integrated with a **Google Firebase (Firestore)** database for real-time, persistent data storage.
